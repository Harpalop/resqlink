# GitHub Feature Workflow

**Context:** Applies whenever a new feature, significant bug fix, or distinct body of work is completed.

**Instructions:**
1. **Commit:** Always stage and commit all changes with a clear, descriptive conventional commit message.
2. **Push:** Always push the branch to the remote GitHub repository to keep it fully synced.
3. **Pull Request:** Automatically initiate a Pull Request for the newly pushed feature so that the user accumulates multiple distinct Pull Requests for their project. Use the `gh` CLI if available, otherwise provide the exact GitHub URL to open the PR.
